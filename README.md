# TaxGo

일본 여행의 면세 환급을 준비하는 모바일 웹앱입니다. 영수증을 정리하고 예상 환급액을 확인한 뒤, 출국 공항의 절차와 일정을 볼 수 있습니다.

## 실행 및 빌드

1. ZIP을 풀고 `TaxGo/dist/index.html`을 모바일 또는 PC 브라우저에서 엽니다.
2. 소스를 편집할 때는 `src/index.html`을 브라우저에서 열어 확인합니다.
3. Python 3로 `python build.py`를 실행하면 `dist/index.html`이 다시 생성됩니다.
4. Node.js에서 `node test/logic.test.js`와 `node test/reminders.test.js`로 계산과 반복 알림을 검증합니다.

서버나 패키지 설치 없이 열 수 있습니다. 웹폰트는 인터넷에 연결되면 불러오며, 연결이 없으면 브라우저의 대체 글꼴로 표시됩니다. 현재 화면은 `preview/final-*.png`에서 확인할 수 있습니다. 이전 버전의 기록은 [v5 변경 기록](CHANGELOG_v5.md)에 있습니다.

최종 UI 점검은 Python Playwright를 설치한 환경에서 `python test/qa_final.py`로 실행합니다. 기본값은 Playwright Chromium입니다. 설치된 Edge로 점검하려면 환경 변수 `TAXGO_BROWSER_CHANNEL`을 `msedge`로 설정합니다. `qa_revision*.py`와 `qa_extra.py`는 이전 UI 버전에서 쓰인 점검 스크립트입니다.

## 주요 기능

| 메뉴 | 기능 |
| --- | --- |
| 홈 | 여행 시점별 안내, 여행 수정, 예상 환급액과 가로 빠른 메뉴 |
| 영수증 | 물품별 금액과 소비 상태 기록, 예상 환급액·등록 합계 및 상태 필터 |
| 출국 | 공항·항구 선택, 공항 도착 목표, 키오스크 안내, 체크리스트 |
| 캘린더 | 여행·구매·기한 일정, 날짜별 메모, 알림 설정과 `.ics` 내보내기 |
| 더보기 | Visit Japan Web 링크, QR 이미지 보관, 여권 정보, 환급 절차 가이드, 면세품 PICK과 일본 면세 OX 퀴즈 |

한국어·일본어·영어와 라이트·다크 모드를 지원합니다. 면세품 PICK은 5개 분류의 25개 제품을 소개하며, 공식 자료와 개인 후기를 구분해 표시합니다. OX 퀴즈는 20개 문항에서 5개를 무작위로 뽑아 출제합니다.

## 계산과 알림

- 예상 환급액은 입력한 영수증을 바탕으로 계산합니다. 앱은 입력 건별로 금액을 계산하고 한 건에 세율 하나를 적용합니다. 같은 매장·구매일의 영수증을 여러 건으로 입력하거나 한 영수증의 세율이 섞여 있으면 예상액이 실제 환급액과 다를 수 있습니다. 공식 자료 링크는 앱의 가이드와 각 퀴즈 해설에 있습니다.
- 공항 도착 목표는 출국 정보와 확인 대상으로 선택한 면세품을 바탕으로 계산하는 앱의 권장 시각입니다.
- 알림은 자동, 지정일 1회, 종료일까지 매일, 매주 또는 매월로 설정할 수 있습니다. 실제 기기 알림은 내보낸 `.ics`를 사용하는 캘린더 앱에서 설정합니다. 이미 가져온 일정에 TaxGo의 후속 변경은 반영되지 않습니다.

## 브라우저 저장

| 데이터 | 저장 위치 |
| --- | --- |
| 여행 정보, 영수증, 출국 체크리스트 | `localStorage`의 `taxgo-v1` |
| 언어, 테마 | `taxgo-ui-language`, `taxgo-ui-theme` |
| 알림 설정, 날짜별 메모 | `taxgo-reminder-prefs-v2`, `taxgo-calendar-memos-v1` |
| 저장한 QR 이미지와 해독 내용 | `taxgo-wallet-qr-v2` |
| 여권 정보 | `sessionStorage`의 `taxgo-passport-session` |

저장 데이터는 브라우저와 출처에 따라 분리됩니다. 파일 경로나 사이트 주소를 바꾸면 이전 데이터가 보이지 않을 수 있습니다. QR 이미지는 최대 8MB의 PNG, JPEG, WebP, BMP, GIF를 받으며, 브라우저에서 해독에 성공하면 축소 이미지와 해독 내용을 저장합니다. 네이티브 QR 해독을 사용할 수 없으면 CDN에서 jsQR을 불러옵니다. 현장에서 필요한 QR은 Visit Japan Web의 공식 화면을 확인하세요.

## 파일 구성

- `src/` — 앱 화면, 스타일, 데이터, 번역, 계산, 면세품 PICK 및 OX 퀴즈
- `dist/index.html` — 배포용 단일 HTML
- `test/` — 계산·알림 테스트와 브라우저 점검 스크립트
- `preview/` — 화면 참고 이미지
- `build.py` — 소스 결합 스크립트
- `DESIGN_SYSTEM.md`, `CLAUDE.md` — 디자인과 코드 유지보수 안내
